# Журнал изменений — Руководство по судейству ОСФ

Формат: по сезонам. Внутри сезона — разделы:

- **Добавлено** — новые правила, ситуации, приложения
- **Изменено** — правки текста правил, перенумерация, изменённые формулировки
- **Удалено** — убранные из источника разделы
- **Редакторская нормализация** — наши правки оформления (не меняют смысл)
- **На проверку** — расхождения и сомнительные места, отправленные составителю (подробности в `ИСПРАВЛЕНИЯ.md`)

Записи вести при поступлении нового исходника сезона, ссылаясь на разделы документа.
